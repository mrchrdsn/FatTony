About the Development Process

Fat Tony was built using an agentic development workflow. I authored the core concepts, architecture, grammar, and semantics, and used AI tools to help iterate on phrasing, examples, and edge‑case exploration. The result is a language that blends deliberate human design with modern AI‑assisted refinement.

The features included in v1 have complete grammar, semantics, and runtime behavior. The language is intentionally minimal, with many features deferred to future versions (arrays, dictionaries, decimal numbers, exceptions, etc.).
